# forklift-surface
The surface crate of Forklift.

## What it is
`forklift-surface` is Forklift's Android program drawn by the native renderer, shipped as `libquench_surface.so`, with the background entry points. Forklift is about the backup of photos, videos and chosen folders.

## Use cases
- Used by the other `forklift-*` crates; see the layout in the [Forklift README](../README.md).
