# forklift-desktop
The desktop crate of Forklift.

## What it is
`forklift-desktop` is Forklift's Linux host: a Wayland window drawn by the native renderer, plus the headless entry points. Forklift is about the backup of photos, videos and chosen folders.

## Use cases
- Used by the other `forklift-*` crates; see the layout in the [Forklift README](../README.md).
