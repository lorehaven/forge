# forklift-core
The core crate of Forklift.

## What it is
`forklift-core` is Forklift's logic with no interface and no I/O. It builds for the browser and the hosts alike, and its tests run natively and fast. Forklift is about the backup of photos, videos and chosen folders.

## Use cases
- Used by the other `forklift-*` crates; see the layout in the [Forklift README](../README.md).
