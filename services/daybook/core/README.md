# daybook-core
The core crate of Daybook.

## What it is
`daybook-core` is Daybook's logic with no interface and no I/O. It builds for the browser and the hosts alike, and its tests run natively and fast. Daybook is about tasks, lists, labels and repeats.

## Use cases
- Used by the other `daybook-*` crates; see the layout in the [Daybook README](../README.md).
