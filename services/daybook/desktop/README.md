# daybook-desktop
The desktop crate of Daybook.

## What it is
`daybook-desktop` is Daybook's Linux host: a Wayland window drawn by the native renderer, plus the headless entry points. Daybook is about tasks, lists, labels and repeats.

## Use cases
- Used by the other `daybook-*` crates; see the layout in the [Daybook README](../README.md).
