# daybook-surface
The surface crate of Daybook.

## What it is
`daybook-surface` is Daybook's Android program drawn by the native renderer, shipped as `libquench_surface.so`, with the background entry points. Daybook is about tasks, lists, labels and repeats.

## Use cases
- Used by the other `daybook-*` crates; see the layout in the [Daybook README](../README.md).
