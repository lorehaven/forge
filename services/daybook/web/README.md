# daybook-web
The web crate of Daybook.

## What it is
`daybook-web` is Daybook's browser build (WebAssembly) over `fetch`, with the page's storage for the session. Daybook is about tasks, lists, labels and repeats.

## Use cases
- Used by the other `daybook-*` crates; see the layout in the [Daybook README](../README.md).
