# daybook-net
The net crate of Daybook.

## What it is
`daybook-net` is Daybook's talk to the services: gatehouse for the session (the shared `gatehouse-client`) and the data service. Plain blocking calls, to run on a worker thread. Daybook is about tasks, lists, labels and repeats.

## Use cases
- Used by the other `daybook-*` crates; see the layout in the [Daybook README](../README.md).
