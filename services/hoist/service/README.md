# Hoist Service
Hoist's public catalogue.

## What it is
`hoist-service` merges the apps of F-Droid, IzzyOnDroid and Aptoide into one row per package, keeps them in Postgres, refreshes every hour, and serves them (behind the realm's login) to the app's Public tab.

## Use cases
- Offer a public app catalogue beside the estate's own registry.
