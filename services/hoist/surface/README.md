# hoist-surface
The surface crate of Hoist.

## What it is
`hoist-surface` is Hoist's Android program drawn by the native renderer, shipped as `libquench_surface.so`, with the background entry points. Hoist is about app installs and updates from the registry.

## Use cases
- Used by the other `hoist-*` crates; see the layout in the [Hoist README](../README.md).
