# hoist-desktop
The desktop crate of Hoist.

## What it is
`hoist-desktop` is Hoist's Linux host: a Wayland window drawn by the native renderer, plus the headless entry points. Hoist is about app installs and updates from the registry.

## Use cases
- Used by the other `hoist-*` crates; see the layout in the [Hoist README](../README.md).
