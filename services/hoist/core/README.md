# hoist-core
The core crate of Hoist.

## What it is
`hoist-core` is Hoist's logic with no interface and no I/O. It builds for the browser and the hosts alike, and its tests run natively and fast. Hoist is about app installs and updates from the registry.

## Use cases
- Used by the other `hoist-*` crates; see the layout in the [Hoist README](../README.md).
