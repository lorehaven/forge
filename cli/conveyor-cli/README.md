# Conveyor CLI

Conveyor CLI (binary name `conveyor`) is the terminal client for [conveyor](../../services/conveyor/service/README.md), the Forge CI/CD service. It talks to conveyor's HTTP API to register repositories, start and inspect runs, stream logs, manage per-repo secrets, and validate `.conveyor.toml` pipeline files.

See [docs/cli/conveyor-cli](../../docs/cli/conveyor-cli/index.md) for full documentation.
