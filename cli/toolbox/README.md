# forge-toolbox
Full-screen monitor and installer for the Forge command-line tools.

## What it is
`forge-toolbox` is a terminal table that shows which Forge tools are installed with `cargo install`, what the private registry offers, and installs or updates one with a keypress. It needs `cargo` and a Cargo registry named `ennor`.

## Use cases
- See which installed tools are out of date.
- Install or update a tool from the private registry.

## Example
```sh
forge-toolbox
```
