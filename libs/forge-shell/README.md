# forge-shell
The frame forge's browser clients share.

## What it is
`forge-shell` is the top bar (dashboard and home buttons, brand, language picker, theme menu, account menu), the side-panel helpers, the stylesheet with the design tokens and components, and the script that keeps theme and palette in step across clients. Not published to a registry.

## Use cases
- Give every service's browser client the same chrome.
- Share design tokens and base CSS between services.
