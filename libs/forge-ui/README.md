# forge-ui
Top bar pieces shared by the forge web UIs.

## What it is
`forge-ui` has the home icon, the user menu and their styles, plus the Untitled UI tokens and the responsive shell (sidebar on desktop, drawer on mobile) used by the server-rendered pages.

## Use cases
- Add the shared top bar to a service page.
- Add only page-specific CSS on top of the shared styles.
