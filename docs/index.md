Forge is the set of services, libraries and command-line tools built on the Quench framework. It is one Cargo workspace.

* [Guides](guides/index.md): architecture, the browser-client pattern, deployment, testing.
* [Services](services/index.md): each service with its OpenAPI description, configuration, data model and operations.
* [Libraries](libs/index.md): the shared crates, documented like crates.io pages.
* [Command-line tools](cli/index.md): every command, flag and interactive mode, with examples.
